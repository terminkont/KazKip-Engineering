# Honeywell ControlEdge RTU2020

## Описание

**ControlEdge RTU2020** — модульное устройство сбора и передачи данных (терминал дистанционного управления) компании Honeywell. Предназначено для автоматизации, дистанционного мониторинга, диагностики и управления технологическими объектами, в том числе в нефтегазовой отрасли.

Устройство интегрируется с системами Honeywell Experion и может применяться совместно с SCADA.

## Основные технические характеристики

| Параметр | Характеристика |
|---|---|
| Номинальная потребляемая мощность | 1,8 Вт |
| Рабочая температура | От −40 до +75 °C |
| Резервирование центрального процессора | Опционально |
| Системы интеграции | Honeywell Experion PKS, HS, PlantCruise |
| Беспроводные устройства | Honeywell OneWireless |
| Ввод-вывод | Встроенные и расширяемые модули с поддержкой HART |
| Дистанционное управление HART | HART IP, Honeywell Field Device Manager Express |
| Программирование | IEC 61131-3 |
| Протоколы связи | Modbus и DNP3 (ведущий и ведомый режимы) |
| Хранение данных | Встроенная память, опционально SD-карта |
| Защита обмена данными | Аутентификация и шифрование |

## Особенности

- Низкое энергопотребление и эффективный теплоотвод.
- Возможность резервирования центрального процессора.
- Дистанционная диагностика и управление устройствами HART.
- Поддержка расчётов для жидкостей и газов в одном контроллере.
- Подавление переходных процессов на каналах ввода-вывода и портах связи.
- Гибкая организация обмена данными и расширение модулей ввода-вывода.
- Конструкция, упрощающая монтаж и техническое обслуживание.
- Сертификация для применения в опасных зонах.

## Применение

Контроль и автоматизация удалённых технологических объектов, прежде всего нефтегазового оборудования, с передачей данных в системы управления и диспетчеризации.

## Производитель

**Honeywell** — серия **ControlEdge**, модель **RTU2020**.
